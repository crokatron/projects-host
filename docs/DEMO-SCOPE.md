# What the demo actually runs

The single HTML file embeds its scripts, styles, data and screenshot tour. It needs no server. A Content Security Policy blocks network connections and remote resources. Controls update a small in-memory example; refresh resets it. Download demo state writes an explicitly labelled JSON example.

This is not the full production application. Dummy HA/CAD/NAS/printer panels are simulations. The QR Print example embeds the MIT-licensed node-qrcode encoder and produces a genuine QR for its sample text, but its tag preview is a 2D illustration, not a fabricated STL/STEP. The mechanical examples state their reduced mathematical assumptions.
