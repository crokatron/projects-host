# Maintain the standalone demo

Edit content.json for project text, runtime.js for this project’s small simulation, and style.css for presentation. figures.json embeds the original screenshots with numbered-box coordinates. Run `python demo-source/rebuild.py` from the repository root to rebuild demo.html. The reader needs only demo.html and a browser.

After changing a screenshot or annotation, review the picture guide and recapture the matching docs/images/guide-N.jpg from docs/figure-N.html. Those HTML figure pages preserve the documentation layout used for the current images. Keep actual-app captures and simulation screenshots explicitly labelled.
